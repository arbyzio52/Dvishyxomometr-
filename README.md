# Движухометр

Статический сайт для GitHub Pages. Загрузите содержимое этой папки в корень репозитория, затем в Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Откройте созданный адрес HTTPS и разрешите камеру.

Показатель рассчитывается по доле белых, синих и красных пикселей и дополнительно увеличивается в зависимости от сходства лиц. Сходство — условный показатель, а не достоверная вероятность. Исходное изображение образца обрезано сверху: если модель не может найти на нём лицо, замените assets/reference.jpg на более чёткое фото с целым лицом. Звук high.mp3 включается от 82%, low.mp3 возвращается при 76% и ниже.

Распознавание выполняется на устройстве, но при первой загрузке библиотека face-api.js и файлы модели скачиваются с jsDelivr: требуется интернет и доступ к этому сервису. Цвета и музыка работают даже при недоступности модели. Камера требует HTTPS или localhost, прямое открытие файла не подойдёт. Все файлы в опубликованном репозитории доступны посетителям, в том числе эталонное фото и аудио.

## Управление и обработка

Повторное нажатие во время подключения отменяет запуск камеры. При скрытии вкладки камера и звук останавливаются. Высокий трек включается от 82%, низкий возвращается при 76% и ниже.

Превью показывает центральную область кадра 4:3: эта же область используется для цветов и сравнения лица. Свой образец можно выбрать в блоке сходства (до 15 МБ); изображение остаётся в текущей вкладке и не загружается на сервер. Кнопка возврата восстанавливает исходный образец. Для анализа нужен доступ к моделям на jsDelivr. Условный процент сходства не является вероятностью идентификации.
