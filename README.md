# Движухометр

Статический сайт на GitHub Pages: ветка main, корень репозитория.

Кнопка запуска открывает камеру на весь экран. Переключатель выбирает один из двух независимых режимов:
- **Цвета**: уровень зависит от доли белых, синих и красных пикселей.
- **Лицо**: уровень зависит только от условного сходства лица в видео с фиксированными образцами `assets/reference.jpg`, `assets/reference-front.png` и `assets/reference-side.png`. Используется наилучшее совпадение среди обнаруженных лиц и пригодных образцов. Образцы без обнаруженного лица пропускаются. Пользовательская загрузка фото отсутствует.

Превью и анализ используют одну центральную область кадра 4:3. Процент сходства — развлекательный показатель, а не достоверная вероятность идентификации. Обработка выполняется на устройстве. Библиотека face-api.js и модели загружаются с jsDelivr; для режима лица нужен интернет.

Звук включён по умолчанию: `high.mp3` играет на низком уровне, `low.mp3` — на высоком. Переход вверх происходит от 82%, обратно — при 76% и ниже. Если браузер заблокировал звук, коснитесь экрана камеры.

Закрытие окна, отмена подключения или скрытие вкладки останавливает камеру и звук. Камера требует HTTPS или localhost и разрешения браузера. После отказа в разрешении доступ можно включить в настройках сайта и повторить запуск кнопкой в окне камеры.
